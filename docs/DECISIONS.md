## Resolved architectural questions (Settled across Milestones)
1. **Database deployment:** Settled via ADR-025 & ADR-026 — PostgreSQL core schema with Alembic versioned migration chain (`0001_initial_core_schema.py`, `0002_signal_persistence_and_provenance.py`), `SignalRepository` idempotent upserts, and managed Neon/Lakebase compatibility.
2. **Embedding model and dimension:** Settled via ADR-007 — Hybrid keyword and TF-IDF semantic vector representation with deterministic clause chunking, zero external API costs, and clause-level traceability.
3. **LLM provider/model:** Settled via ADR-007 & ADR-030 — Deterministic rule-based and citation-grounded RAG copilot engine with honest abstention guarantees (`abstained: true`), eliminating numerical hallucination.
4. **Risk target horizon:** Settled via ADR-003 & ADR-027 — Disruption within 30-day operational horizon, holding out `SUP-1047` degradation window (`period_date >= 2026-07-01`) from training data.
5. **Score mapping:** Settled via ADR-003 & ADR-027 — Governed 0–100 risk score formulated per Section 12.2 from calibrated ML probability plus external signal and operational factors, with explainable top driver decomposition.
6. **Approval threshold / roles:** Settled via ADR-008 & ADR-031 — Governed Policy Engine enforcing RBAC role limits: read-only `ANALYST`, `PROCUREMENT_MANAGER` up to ₹10,00,000, and `CPO` authorization for material multi-source commitments.
7. **Data source list:** Settled via ADR-004, ADR-021 & ADR-032 — Canonical external adapters (GDELT, Marketaux, Alpha Vantage, NewsData.io, SEC EDGAR) protected by SSRF whitelist shield, rate limiting, and exponential backoff.
8. **Model and RAG thresholds:** Settled via ADR-003, ADR-007 & ADR-027 — Acceptance thresholds frozen: ROC-AUC >= 0.60, Brier score <= 0.25, ECE <= 0.15, RAG similarity threshold >= 0.40 with 1 Critic retry cap.
9. **Hosting & Deployment:** Settled via ADR-010 & ADR-033 — Sovereign self-contained enterprise stack (FastAPI backend with structured JSON logging and distributed tracing, React/Vite frontend bundle, zero external mandatory dependencies).
